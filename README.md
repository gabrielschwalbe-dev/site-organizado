# Boas Práticas Front-End: Tecnologia e Desenvolvimento de Sistemas

## Objetivo do Projeto
Este projeto tem como objetivo aplicar conceitos fundamentais de desenvolvimento web utilizando **HTML5** e **CSS3**, com foco em organização de código, semântica, separação de responsabilidades e versionamento com Git e GitHub.

## Estrutura do Projeto
- `index.html`: Estrutura semântica da página contendo cabeçalho, menu de navegação, seções informativas e rodapé.
- `style.css`: Estilização externa responsiva utilizando Flexbox e CSS Grid.
- `README.md`: Documentação do projeto.

## Como foi desenvolvido
1. Criação da estrutura base em HTML semântico (`header`, `nav`, `main`, `section`, `article`, `footer`).
2. Estilização em arquivo CSS separado, aplicando reset básico, variáveis visuais consistentes e layout adaptável.
3. Revisão de nomenclatura de classes e indentação para garantir legibilidade e manutenção.
